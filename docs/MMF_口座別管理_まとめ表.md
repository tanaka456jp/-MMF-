# 外貨建MMF：一般口座・特定口座の一体管理とまとめ表

## 対象
同一銘柄について、Excelブック内の「一般口座」「特定口座」それぞれで取得費・残高を計算し、両者を「口座別まとめ」に集計する。移動平均の計算ロジックと為替換算は従来の各台帳を利用する。元の「MMF取引台帳」は移行後も非表示の原本として残す。

## VBAUpdaterで反映後の初回起動
1. GitHubの最新mainをVBAUpdaterで反映し、ブックを保存して開き直す。
2. 既存の「MMF取引台帳」に取引がある場合、移行先を選ぶ。**はい＝一般口座、いいえ＝特定口座、キャンセル＝中止**。選んでいない口座は入力欄を空にした状態で作成する。初期取引を両口座へ二重登録することはない。
3. 「一般口座」「特定口座」の2シートが作成され、元台帳は非常時用として保持される。
4. 両口座の取引内容・計算状態に問題がなければ、「口座別まとめ」も自動作成される。

## 既存の別ファイルから残りの口座データを移す
「口座別まとめ」シートの**別ブック取込**ボタン、または `Alt+F8` → `MMF口座_別ブックから取込` を実行する。

- 移行元は**読み取り専用**で開く。外部ブックのマクロは起動させない。
- 受入先が空欄であること、B3（銘柄）・F3（通貨）が一致すること、元シートが互換形式であることをチェックする。
- 既存取引や期首残高を**無断で上書きしない**。
- 取引・期首残高を取り込んだ後、入力判定K列がOKになることを確認する。
- この簡易取込は**500取引行以内**に対応する。500行を超えるデータや複数銘柄を自動的に結合しない。

## まとめ表の項目
添付の見本に合わせ、取引期間（開始・終了）、備考、**特定口座の数量増減／残高**、**一般口座の数量増減／残高**、取得単価（円/口）、合計残高（口）、合計残高（外貨）を表示する。年末は「YYYY年12月31日現在」の残高行を自動挿入する。

「口座別まとめ」右側の設定（印刷範囲外）：
- **K2：1口当たり外貨額**。既定値0.01。銘柄の単位と異なる場合は変更する。
- **K5：表示単位**。「年次」（初期値）、「月次」、「明細」から選ぶ。「年次」「月次」では同方向の買付・売却を期間ごとに集約する。
- **まとめ表更新**：取引台帳を再集計して一覧を更新する。
- **A4まとめ印刷**：A4横・横幅1ページで印刷ダイアログを開く。複数ページ時は見出しを繰り返す。
- 各口座の**A4印刷**：クリック元の口座を対象として既存のA4縦の取引明細を印刷する。

## 税務・残高の注意
- **取得費・移動平均法は一般口座と特定口座で別々に計算する**。まとめ表の取得単価（円/口）は両口座の円貨簿価の加重平均による**参考値**であり、課税計算で異なる口座を自動合算するものではない。
- **口座間移管は税務上の売却と同義ではない**。今回の2口座まとめ機能は、移管を移動平均計算へ自動で反映する機能を備えていない。既存の「買付数量」「売付数量」を機械的に移管へ流用せず、移管日・移管数量・引継ぎ簿価の整合確認を要する。
- 明細の入力判定（K列）がOKでない行、日付が逆順の行、合致しない銘柄・通貨は、誤集計を避けるため自動集計を中止する。
- 取引入力や元データの訂正後は「まとめ表更新」を実行する。印刷直前にも再集計される。
- VBAと印刷レイアウトの**Windows Excel実機検証は別途必要**。GitHub ActionsのCIは静的検査。
